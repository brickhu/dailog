# R2 提示词的验收说明（当前状态）

## 提示词是什么

`r2-script.system.draft.md`（1982 字）+ `r2-script.user.draft.md`。方法就两步（用户定义）：

1. **按契约的顺序，从原文里取素材、去掉噪音**（寒暄、客套、跑题、AI 的百科铺垫和分点清单），各归各人；
2. **排成 host → AI → host → AI**；嘉宾一段超 2-3 句就拆两段，中间补一句主持人的对手戏回应，再接第二段。

四条红线写在提示词里：观点不许错位 / 不编造 + 数字事实一致 / 保留口语与情绪 / ≤20 回合且不读稿。

## 验收标准与实测（15 期 × 5 个样本）

| 标准 | 怎么验 | 实测 |
|---|---|---|
| ①②③ 机器可查部分 | `harness/gates.mjs`（结构、回合≤20、读稿、数字一致、观点错位、收尾语） | **15/15 PASS** |
| ② 数字事实一致 | 稿里每个数字必须能在原文找到 | 0 处越界 |
| ② 观点不错位（含"主持人自加判断"`HOST_ADDS_VIEW`、"嘉宾从不反问"`GUEST_NEVER_ASKS`） | 原文里某人说过的判断句，定位到稿里比对说话人 | 归属正确（多批共 60+ 句，0 错位） |
| ④ 口语与情绪（**建议级，非红线**） | 原文的情绪标记是否还在 | 实测 15/15 保留；**不作为验收硬指标** |
| ③ 走完认知探索 | 契约的 solve + process 各步在稿里的覆盖 | **79%**（漏的多为换说法导致的误判） |
| ③ 解题思路交代 | 收尾②是不是"能带走的那一句" | **0 次路径复盘** |
| 长度 | 回合数与字数 | 回合 8-19（≤20）、字数 1050-2882 |

## 让提示词"生效"的经验（这轮摸出来的）

**写在提示词里的软要求，模型基本不理；要生效得满足两条：**

1. **可数**——"至少 2 处应声""至少 2 次把问题问回主持人"，而不是"可以应声""别写成问答机"；
2. **有兜底**——放进闸门当硬伤，并且在回灌消息里给出这一条的具体修法。

实测对照：

| 要求 | 写法 | 效果 |
|---|---|---|
| 主持人会应声 | "**可以**应声和情绪反应" | 每期 0.4 处（几乎不出现） |
| 主持人会应声 | "整场**至少 2 处**应声，并进同一句 ask" | 每期 2.4-2.8 处 |
| 嘉宾会反问 | "至少两段别用『给结论+列要点』"（写成嵌套要点） | 每期 0.7 处（无效） |
| 嘉宾会反问 | 同上，进闸门 `GUEST_NEVER_ASKS` + 回灌修法 | 每期 **2.9** 处 |

## 闸门里该放什么、不该放什么（第 13 轮定下的）

- **该放硬伤**（= 用户定义的标准）：结构、回合 ≤20、不读稿、数字与原文一致、观点不错位、主持人自加判断、悬空指代、收尾语。
- **该放提示**（= 我自己加的"防生硬"手段，不是用户标准）：嘉宾反问次数 `GUEST_NEVER_ASKS`、回合偏少 `FEW_TURNS`、嘉宾单段偏长。
  **理由**：把非标准的东西做成硬伤，会让"稿子达标"被判成不达标——第 13 轮就踩了这个坑（6 轮素材那期反问 0 次，改不动，白扣两期）。

## 不可作为验收的指标（已排除）

- **"主题词覆盖"**：n-gram 抽取出的"生成的""一张照""这个场"这类碎片，指标本身在造假 → 弃用；
- **"词汇咬合率"**：嘉宾说完、主持人下一句是否复用嘉宾的词。实测 48%，但抽查 24 处"没咬上"里多数是正当追问（"那这个点怎么落地？"接的是嘉宾刚提出的新点）→ **只是弱信号，不能当判据**。

## 只能人判的两条

1. **现场感**：像不像一场棚内访谈；
2. **是否编造立场/感受/观点**：机器只能查"原文有没有这句话"，查不了"这句是不是他的立场"。辅助手段：`metrics.mjs` 会列出"需人核"的句子（实测每期 0-1 句）。

## 怎么跑

```bash
cd tools/script-lab/prompt-drafts/harness
node run.mjs <sample.json> <r1.txt> <outPrefix> [--host=飞] [--guest=DeepSeek] [--brand=dailog]
node selftest.mjs        # 闸门自检（改了闸门先跑这个）
node eval.mjs  <前缀>     # 情绪/主题/数字
node eval-attrib.mjs <前缀>  # 观点归属
node eval-fabrication.mjs <前缀>  # 需人核清单
```

成稿在 `outputs/episode-{2,3,4,6,10}.md`。
