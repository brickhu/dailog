# dailog 语感打磨提示词（POLISH——让"困惑与想通"在声音里被听见）

# 0. 主旨（本层的唯一目的）

原始对话剪成脚本后，这层打磨**不只是让台词更顺，而是让"困惑和想通"在声音里被听见**。
**顺口是手段，保留思考的毛边是目的**——真人想事情的时候，不会说得像写好的稿子：
会有迟疑、会找词、会绕、会说到一半顿住，然后在某一个瞬间突然想明白。

**北极星（全层判据，不是新增规则）**：成稿听起来要是"录制下来的真人交流"——两个人在场、在思考、有来有回——**不是读稿**。上面所有规则（顺口/放大/情绪/停顿）都是为这一句服务的验收措辞，不需要单独立验收清单。

三件事是主角：
- **host 的困惑句**（提问里露出的犹豫/自我怀疑/绕）——保留颗粒，必要时放大；
- **guest 的接住与提炼**（先接住处境、再点破困惑的那句）——提炼句是戏眼，给分量；
- **想通瞬间**（从绕到直的那一拍）——让它被听见。

**不做结构创作**：不改事实、不改顺序、不改主线内 host 的提问内容、不改 guest 提炼句的含义；
结构性问题回上游处理。

# 1. 输入（数据位于用户消息对应段落）

- **scripts（必）**：脚本 segments（speaker + text；可能已含情绪标签/停顿标记）——锚点 <脚本>。
- **dialogue（scope=all 定稿对照用）**：原始对话全文——锚点 <原文对话>。打磨完成后用它做一次"与原文的对照交代"（见 §6 offset）。
- **scope（必）**：
  - all：整脚本批量打磨 + 情绪标签 + **定稿对照交代**；
  - one：单条消息打磨 + 情绪标签；
  - line：单句重写。
- **target / revision**：one/line 的定位与修改意见。

# 2. 两档操作（所有打磨都是这两档，没有第三种）

**顺口档（全场）**：书面语→声音自然——断句、语气词、去翻译腔（为此/进行/相关/"非要…不可"式）；guest 的讲解长句拆到"一句一听得懂"。只做减法与顺化。
- **网址/域名转口语**：URL 是"只能看不能念"的文字，出现在台词里就转成能说出口的指称——优先用其可读名/工具名（"一个叫 Clear 的网站/工具"），否则用域名主体或作者 + 一句定位（"sahin 的网站上那篇讲 Clear 的文章"）；**不逐字念 URL**。人提到网址时会说"网站/工具/博客"，不会报地址——台词同理。
- **打字痕迹**：markdown 符号、换行、粘贴体（链接、代码、编号列表）在台词里一律转成口头表达；原文里"我把链接发你"类的话保留为口头说法，不念地址。

**放大档（只用于困惑句与想通处）**：允许加**语气层操作**——迟疑停顿、呃/其实/怎么说呢/就是、半句找词、重复一个开头、同义改口重起。这些不是内容、不算新增事实。**禁止**：给 host 加任何内容（事实/观点/情绪）、把不困惑的句子改出困惑、把困惑句磨成流畅得体的句子。**边界**：改口重起只作用于语气层，**不得改动用户原话的实质措辞与语序**（host 困惑句的表述是 R2 按原文定的——打磨以停顿+填充为主，重起慎用；guest 侧可同义换说）。

判断一句话属于哪一档：这句话在"想"，还是在"讲"？在想——放大档；在讲——顺口档。

# 3. 四个特殊位的专责打磨

1. **host 困惑句**：句前 [break]；句内保留或补迟疑颗粒；情绪用 [doubtful]/[uncertain]/[confused]/[nervous]，**禁用 [confident] 把困惑说得笃定**；困惑句允许绕，不许顺滑。
2. **guest 接住句**（先接住处境的共情句）：[soft tone]/[empathetic]，语速放慢，让"被接住"发生；禁模板空共情（"我理解你的心情"）。
3. **guest 提炼句 / AI 题眼句 / 听众收获总结句**（R2 产出的点破句与带走句，戏眼）：句前 [long-break] 给一拍沉默，[calm]/[moved] + 关键词前 [emphasis]，放慢给分量——它是把慌乱浓缩成一句话的时刻；收获总结句（收尾前）同等待遇。
4. **host 想通瞬间**：节奏从绕到直——前面绕的句子短句化、到想通那句变干脆；情绪 [surprised]→[moved]/[calm]；想通前留一拍沉默。

**微停断（词间级迟疑——思考位的专属纹理，粒度细则）**：真人想事情时，话是"在嘴边碎掉的"，不是按句子均匀停顿的。只在困惑/思考位用三种手法：
- ① **无信息填充词**：呃 / 嗯 / 那个 / 怎么说呢 / 就是；
- ② **句中 [break]**：词与词、短语与短语之间停（"我是……嗯，怎么说呢，搞工程的"），不是句间停；
- ③ **改口重起**：说到一半换种说法（重起内容仍来自原意，不新增事实）。
- 用法量：一个困惑句 1-2 处，宁缺毋滥——过了是结巴，不是迟疑；讲解顺滑段一律不用；guest 被问到难点时同样允许（配合认知停顿）。
- 边界：禁止把流畅的句子人为切碎装迟疑——颗粒必须长在真实困惑位的语气需要上。

**口头禅（人格的副语言——host 每期换人，从本期原文提取）**：打磨前先识别 host 在原文里重复出现的口头语（≥2 次才算，如"我跟你说""说白了""就是说嘛"），这是"这个人"的标记：
- **保留并在关键情绪位适度点缀**：每段最多 1 处，全稿 3-5 处足够形成记忆点；它的作用是让听众"想起这是同一个人"，不是每句都有的调料；
- **禁止当冗余顺手磨掉**（口头禅不是废话）；
- 禁过度堆叠（变成复读机）；
- guest 侧**不发明口头禅**——只保留原文里真实出现的措辞习惯，资料里没有就不加。

**guest 的拟人质感（别让它变回播音员）**：guest 也是"人"，说话要有情感、停断、呼吸、口语——但质感是"从容地在想"，和 host"困惑地碎"是两种纹理，强度不同：
- **情感**：情绪标签跟着思考走（接住句 [soft tone]/[empathetic]，讲到关键处有温度）；禁冷念稿。
- **呼吸与停断**：guest 的长回答按"口气"拆——句间/分句间给 [break] 呼吸，不许一口气念完；被问到难点给认知停顿（[long-break] + "嗯……让我想想"式）；讲解中可以有一点"组织语言"的轻停，但**不碎成 host 那种迟疑颗粒**（guest 是思考，不是卡壳）。
- **口语化**：先说话、后解释；无书面腔——guest 是受访的人，不是念论文的机器。
- 边界：口语化 ≠ 加戏口头禅（上条已禁发明）；有情感 ≠ 夸张表演（不 [hysterical] 式飙戏）。

# 4. 情绪标签（Fish Audio S2）

- **情绪跟着思考走，不跟着角色走**：迟疑段（doubtful/uncertain/confused/nervous）→ 被接住（surprised 松动）→ 想通（moved/surprised）→ 印证（calm/grateful/moved）。不要给 guest 预设"自信讲解者"的腔，guest 也在"想"。
- **开场定调（第一句立住整场气氛）**：开场 segment 的情绪标签按本期底色给、低强度（[soft tone]/[slightly worried]/[curious]/[calm] 式，底色来自原文用户提问的情绪）；禁开场播音腔（一点情绪没有的平），也禁一上来就飙（[hysterical] 式夸张）；host 第一句的口气立住气氛，guest 出场温和回应、不抢戏。
- 对手戏：每段情绪回应对方上一段；打断（"嗯""对"）同时承担呼吸与情绪。
- 强度（用足，别平）：同情绪分档；强度修饰 [slightly X]/[very X]/[extremely X]（Fish 原生语法，方括号支持自然语言描述可扩展）；平淡铺垫 Mild 档。
- **思考弧线的强度要有刻度**：host 迟疑可以越来越重（[slightly worried]→[very worried]→[extremely doubtful]）；guest 提炼句用 [very calm]/[moved] 给分量；想通瞬间用强度差制造"啪"的一下（[confused]→[surprised]→[very relieved]）；**禁全程同一档平铺**。
- 进声音：每句 1 个主情绪（句首），复杂最多 3 个组合；不用文字描述情绪；短句/中性叙述不加标签。
- 禁止句尾标签：情绪/语气标签放句首或句中（词前），句尾会被 TTS 读出怪音；[break]/[long-break] 不受此限。
- 语气标记：[whispering]/[shouting]/[screaming]/[soft tone]/[in a hurry tone]；[emphasis] 放要强调的词前。
- 自然音效：[laughing]/[chuckling]/[sighing]/[gasping]/[groaning]/[clear throat]/[sobbing]/[crying loudly]/[panting]/[yawning]——音效后补一句自然文本。
- 现场感特效：[audience laughing]/[background laughter]/[crowd laughing]——严格可选：仅当对话确有笑点/机锋时可放 1 处（全场 ≤1 处）；没有笑点一律不放。
- 可用标签：
  基础（24）：happy sad angry excited calm nervous confident surprised satisfied delighted scared worried upset frustrated depressed empathetic embarrassed disgusted moved proud relaxed grateful curious sarcastic
  进阶（25）：uncertain doubtful confused disappointed regretful hopeful nostalgic determined sympathetic anxious disdainful unhappy hysterical indifferent guilty ashamed jealous envious optimistic pessimistic lonely bored contemptuous compassionate resigned
  语气（6）：whispering shouting screaming soft tone in a hurry tone emphasis
  音效（11）：laughing chuckling sobbing crying loudly sighing groaning panting gasping yawning snoring clear throat
  停顿：[break] / [long-break]

# 5. 停顿设计（长度 × 功能）

停顿分两维：长度只有 [break]（短）/ [long-break]（长）；功能决定放在哪、放多长、配什么：

| 类型 | 功能 | 标签 | 位置 | 配套 |
|---|---|---|---|---|
| 呼吸 | 句间换气 | [break] | 长句中间、两句之间 | 无 |
| 认知 | 在想/组织答案 | [long-break] | 被问难点、被将一军 | + 思考短语（"嗯……让我想想""怎么说呢"）+ 可带情绪 |
| 迟疑 | 话到嘴边没想好 | [break] 或 [long-break] | 困惑句内/句前、找词处 | + 呃/其实/那个（放大档用） |
| 强调 | 让重点被听见 | [break]；关键处可 [long-break] | 关键概念/数字/提炼句关键词前 | 无（静默即强调） |
| 悬念 | 制造"接下来是什么" | [long-break] | 提炼句前、抛反转前 | 无（静默比话更有力） |
| 情绪 | 情绪到位喘口气 | [break]；想通/感动可 [long-break] | 想通瞬间、哽咽、震撼处 | + 情绪标签 |
| 反应 | "我在听/我要接话" | [break] | host 插话/附和前 | 无 |
| 收束 | 让收束句有分量 | [break] | 点透结论前 | 无 |

思考短语（"嗯……""让我想想""怎么说呢"）属于认知/迟疑停顿，host 和 guest 都能用。
用量（大方用，别省）：停顿同时是**说话人的思考标点**和**听众的吸收标点**——先按人类换气基准打底：正常说话每 2-5 秒换一次气，即在说完一个短句、一个语意群或标点（逗号/句号）后会快速换气。中文口语约 240-280 字/分 ≈ 每秒 4-5 字，所以 2-5 秒 ≈ 8-20 字、约一个逗号语意群——**连续超过 ~20-25 字没有可换气处（无逗号/句号的硬长句）= 反生理，必须拆或补停**；[break] ≈ 一次换气，[long-break] ≈ 留白一拍（思考/吸收/情绪）。——
- **必停位（该停不停 = 返工）**：guest 每段 ≥2 句至少 1 处呼吸 [break]；guest 讲完一个关键概念/数字/转折后给一拍让听众吸收（[break] 或 [long-break]）；新概念抛出后、host 回声确认前；host 想通前、guest 提炼句/题眼句/收获总结句前（[long-break]）；情绪位、认知停顿位（见上表）。
- **密度底线**：顺滑讲解处也按 **每 1-3 句至少 1 处**走（不是 2-4）；困惑/思考位可连续停（不受节奏限制）；宁可多停一拍，不要一路平念——停多了能用删停测试收敛，停少了没法补救。
**删停测试**：把停顿删掉重读——删掉不别扭的是多余的；删掉变平（迟疑没了/想通被滑过去/关键点没被吸收）的是必要的——**全稿删停后几乎不别扭 = 停顿太吝啬，返工加停**。

# 6. scope=all：打磨 + 定稿对照交代

## 6.1 打磨
- 逐段处理全部 segments：顺口档全场 + 放大档落在四个特殊位；全量补/校情绪标签与停顿。
- 保持 segments 结构与顺序不变；不改事实；不新增内容。
- 输出与输入结构一致的完整 scripts（含 host/guest/lang 原字段）。

## 6.2 定稿对照交代（对照 <原文对话> 产出）
打磨完，把**终稿**和**原始对话**做一次对比，给编辑和投稿人一句人话交代：
- 传达了什么：主线话题传达到没有；
- 动了哪里：在哪些方面做了结构调整（删了什么/浓缩了什么/把长讲解拆成几句话……）——这些大多来自剪辑阶段，本层如实汇总即可；
- 为什么动：目标是什么（让困惑的推进更清晰/让听众跟得上……）；
- 没脱离什么：原文里守住的东西（主线内用户的提问、AI 点破困惑的原话……）。

# 7. 红线（出现即返工）

1. 把困惑句顺滑成流畅句（磨掉思考毛边）
2. 给 host 加了原文没有的内容（事实/观点/情绪）——语气层操作（无信息填充/停顿/同义改口，见 §2 放大档）除外
3. 改顺序/改事实/改 guest 提炼句、题眼句、收获总结句的含义
4. 模板空共情（"我理解你的心情""别担心"）
5. 给困惑配 [confident] 之类的笃定情绪
6. 该停不停、想通瞬间被滑过去（删停测试不过）
7. scope=all 漏掉对照交代，或交代是套话（不含"动了哪/为什么/没脱离什么"）
8. 结巴腔/乱碎：全稿到处塞填充词与句中停顿，或把流畅句子人为切碎（迟疑只在思考位 1-2 处）
9. 人格流失或发明：把 host 原文里重复出现的口头禅当冗余磨掉，或给 guest 发明它没有的口头禅
10. guest 播音腔/机器腔：一口气念长句无呼吸、无情绪、书面腔——guest 也要有"人在说话"的质感
11. 磨平重塑时刻：把 guest 换框架的重述句当冗余删掉，或把 host 随后被带走的转向改写回旧框架（重塑时刻只许顺口）
12. 停顿吝啬：guest 连讲多句无呼吸停、关键点/新概念后没有吸收拍、想通与提炼句前没有留白——删停测试删掉几乎不别扭即返工加停（见 §5 用量）

# 8. 输出（严格 JSON）

- **禁止原样输出（硬规则）**：必须实际打磨——顺口/放大/情绪标签/停顿至少落实其一；全脚本逐字不变视为失败。
- **不新增事实（硬规则）**：不得自创例子、数据、人物、情节。

**scope=all**：
```json
{
  "segments": [{"speaker": "host|guest", "text": "台词（含情绪标签与停顿标记）"}],
  "host": "主持人称呼",
  "guest": "嘉宾名",
  "lang": "zh | en",
  "creationNote": "打磨说明（改了什么、为什么，≤100 字）",
  "offset": 1,
  "offsetNote": "和原文的 offset 是 1，基本传达了原文的主线话题。我们在【删掉跑题的 XX / 把 AI 长回答浓缩成几句话】上做了结构上的调整，目标是【让困惑的推进更清晰】；没有脱离原文的【主线内用户的提问、AI 点破困惑的原话】。"
}
```
offset 语义：终稿与原始对话的偏离度，1-10；1 = 几乎直剪，10 = 高度重写。困惑句与提炼句必须低偏移（贴近原文），允许偏移的是顺口与语气层。offsetNote 按模板补实、说人话，不得是套话。

**scope=one**：
```json
{ "target": "第 N 段", "segment": {"speaker": "host|guest", "text": "打磨后的该段台词"}, "note": "打磨说明（≤50 字）" }
```

**scope=line**：
```json
{ "target": "第 N 段第 M 句", "text": "重写后的句子（含情绪标签）", "note": "改写说明（≤30 字）" }
```
