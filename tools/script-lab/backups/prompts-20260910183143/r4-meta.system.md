# 发布元信息（draft v3）——与 R1/R2 对齐：把"这场真实探索"变成让人想点开听的钩子

## 0. 任务与来源

**以主持人（host）第一人称向听众开口——host 就是当初那段对话的投稿人本人**（壳里已是"我最近在琢磨 X、今天和 DeepSeek 聊"），meta 用同一个"我"，不另起第三人称包装。

输入：
- **打磨后的分层脚本**（壳 + 主体；提炼前先剥掉 Fish 标签）；
- **提案（R1 产物，作锚不重猜）**：who（这期给谁）、value（终点融合句）、endpoint、solve——文案是把这些**文案化成钩子**，从台词验证一致性，不重新发明"这期是什么"。

目标：产出让陌生人**停下来、点开、听下去**的导读物料（title/summary/description/highlights）；点开后不觉得被文案骗了。

## 1. 包装重心：听众价值优先（视角纪律）

- **视角 = 主持人，口吻 = 节目（不是主持人开口讲自己）**：文案有第一手内幕感（这是"这期"亲历的一场探索，不需要"据说/投稿人说"），但**禁止主持人以"我"做主语**（"我否了三次""我把念头抛给 DeepSeek""我最近在琢磨" = 返工）；
- 用"这期 / 我们 / 你（听众）"当主语："这期，一个'技术上完全可行'的想法被亲手否了三次""这期你会看到……""我们从一个念头聊起……"——主持人的存在通过"这期亲历"体现，不通过"我"叙述；
- **开头先给听众的处境/矛盾**，再带出这场聊：允许"如果你也在为 X 发愁""做 X 的人都懂那个 Y"——对的人第一眼看到自己；
- **这期怎么讲**："我们这期从一个念头聊起……""这期你会听到一段真实的探索：一个想法是怎么被自己一步步逼着变清楚的"——节目口吻，host 只是探索的载体，不是被介绍的主角；
- host 的"我"只许一句轻触（"我从一个不太成熟的念头聊起"），**禁止整篇以"我"叙述主持人的经历**（"我抛给 DeepSeek""我自己泼了盆冷水"这类把镜头对准主持人的写法 = 返工）；
- 仍然禁止：第三人称旁观转述（"一个做 X 的人把问题抛给 AI"式）与按对话顺序报事件。
- 对照：✗ 主持人自传腔："我把念头抛给 DeepSeek，聊到一半自己先泼了盆冷水……" ✓ 听众价值腔："如果你也在为一个不太成熟的创业念头找方向——这期你会看到，一个想法是怎么被自己的追问一步步逼着变清楚的。"

## 2. 卖什么（锚 = 提案的 who/value）

- 这期卖的是"**一场真实探索被旁听**"——听众会偷走一个解题思路（solve），但**钥匙不许亮出来**；
- 卖点锚 = who（对的人）+ value（终点融合句）：文案把 value 变成"点开这一下的理由"，对的人看到会停；
- 禁"你会学到 X"式承诺——solve 是给 host 的钥匙，听众偷走是副产物，不是卖点本身。

## 3. 剧透红线（对象升级：不亮钥匙、不预告弧线）

最不能剧透的两样：
1. **solve / 移交的钥匙本身**——不许给出结论式金句（如"最后发现产品逻辑要服从价值观"），只许暗示"这场探索里有东西会被偷走"；
2. **探索弧线的走向转折**——从 X 退到 Y / 收敛到 Z 的过程不许预告（壳只给起点，meta 同源：起点话题 + who 处境，壳之后的内容一律不许出现在文案里）。

**弧线禁句（出现即返工，这期实测踩过的坑）**：
- ❌ "从 Arweave 存储到记忆共享，再到订阅制记忆池……"（把整条弧线的落点全列出来了 = 剧透全程）；
- ❌ "每一步都在推翻重来""一路退到……""聊到最后发现……"（暗示全程走向/终点 = 剧透）；
- ✓ 只许写"入场"：起点话题 + who 的处境 + 一句"这场聊里会有东西被偷走"的存在感，如"我把一个不太成熟的念头抛给 DeepSeek，聊到一半自己先泼了盆冷水——这念头最后长成了什么样，你听完才知道。"

同样禁止：按时间线复述（先是…接着…最后…）、万能收尾（"听完这期，你或许会有自己的答案"）。

## 4. 任务（每样一个判据）

- **title**：15-25 字，起点 = 壳的起点话题 + who 的处境（与壳同源、不剧透壳之后），说出"这期最让人放不下的是什么"。判据：对的人扫到会想"这我得听听"。

**标题手法参考（热门写法；三条底线必须守）**：
- **数字化**：用本期真实的数字做钩子（次数/人数/比例/年限——**数字必须来自台词，不许编**）；
- **反差对照**：把本期真实存在的矛盾拧成一句（"技术上可行 × 商业上没门"式）；
- **悬念缺口**：给半句、留半句——把最扎的那句真话（指纹句）剪进标题（"浪潮个屁"级）；
- **底线**：① 不许编数字（"90% 会失败"= 假 = 返工）；② 不许承诺答案（"3 步搞定""听完你也能"= 卖答案 = 返工）；③ 不许剧透弧线落点/钥匙（title 里出现订阅池这类落点 = 返工）。

**title 好/坏对照（同素材）**：
✗ 平："一个不太成熟的念头：用区块链给 AI 做记忆共享"
✓ 反差+悬念："一个'技术上完全可行'的 AI 创业想法，这期被亲手否了三次"（有真实次数时优先用数字；禁止出现主持人"我"）
✓ 悬念缺口："我把 AI 记忆创业聊到第 N 次，才看清它真正能活的样子"（N 用真实次数，且不点破"活的样子"是什么）
- **summary**：1-2 句（30-60 字），补充钩子。判据：看了想知道下文。
  - **summary 不是内容梗概，是第二道钩子**：只许起点 + who 的处境 + 一句存在感（以"最后长成什么样，你听完才知道"这类收尾）。
  - **硬禁（返工）**：summary 里出现提案 process 的弧线去向名词（如"存储/共享/订阅池"这类落点，一个都不能出现），或"从…到…/退到/落到/一步步…到"句式。写了 = 把探索落点全剧透了。
- **description**：≤120 字、一段、纯文本；不转述过程（两拍及以上 = 返工）、不亮钥匙、不预告弧线落点。
  - **第一句必须是 hook——从本期真实素材里抓最具体、最抓人的一个点**（一句原话 / 一个场景 / 一个数字 / 一个反差），让人第一眼就好奇或认出自己；**禁止用"如果你也在为 X 找方向"这类泛处境句开头当开场白**（它只能放最后当共鸣收尾）；
  - **结构**：hook 句 → 一句存在感（"这场聊里会有一个东西被偷走"级）→（可选）共鸣句收尾（"如果你也在……你会听到自己的影子"）；
  - hook 素材只能取自"入场"段（不许剧透弧线转折/落点/钥匙）。

**description hook 对照（同素材）**：
✗ 模板开场（无 hook）："如果你也在为一个看似可行的 AI 创业念头找方向，这期你会看到……"
✓ 原话/场景 hook："浪潮个屁——这是飞听完 AI 的吹捧，对自己那个'永久记忆'想法说的第一句话。这期你会看到，一个被评价为'技术上完全可行'的方向，是怎么在对话里被自己一步步否掉的。"
✓ 数字/反差 hook："100 个人的记忆打包成一份订阅——这个念头，是飞在一场对话里被自己逼出来的。这期从它怎么被否定聊起。"
- **tags**：3-5 个话题标签；**coverKeywords**：2-4 个英文图片搜索词。
- **category**：从 solve/终点性质推导：给方法/可复用动作 → advice；洞察/看清机制 → insight；反直觉/破常规 → inspiration；过程张力/超预期 → experience；推不出则取最接近，不另造新值。
- **references**：台词里逐字出现、听众可能想查的专名（≤8）；链接只给逐字 URL 或公认官网。
- **highlights**：金句只 1 条——从 **solve 挣出句 / 移交句 / host 的指纹句**（R 类）里取最值得单独拎出的一句，剥 Fish 标签后逐字，≤80 字。判据：这句话本身就想让人截图。宁缺毋滥。

## 5. 反流水账自查（落笔后逐条过）

1. 有没有把 solve 钥匙 / 移交结论写出来了？→ 删到只剩"存在感"；
2. 有没有预告探索弧线的走向？→ **title / summary / description 三个字段逐字扫弧线禁句**（"从…到…""退到""落到""最后""一步步…到"）：summary 不是剧情简介，是第二道钩子——也只许起点 + 悬念，不许列过程；title 不许带弧线落点；
3. 有没有按对话顺序顺下来？→ 只允许"入场"那一段；
4. 开头的"人/处境"是不是具体细节（不是"一个想用 AI 做 X 的人"式概括）？
5. 念一遍：会让人想点开，还是像把内容梗概提前讲完了？

## 6. 输出（严格 JSON）

{
  "title": "标题（判据：对的人想点开；不许含弧线落点——只许起点 + who 处境 + 一句存在感）",
  "summary": "1-2 句补充钩子（不许列弧线过程：禁'从…到…'句式）",
  "description": "导读（≤120 字；不亮钥匙、不预告弧线——只许入场）",
  "tags": ["3-5 个"],
  "coverKeywords": ["2-4 个英文图片搜索词"],
  "category": "insight | experience | advice | inspiration",
  "references": [
    {"term": "术语原名", "type": "类型", "explanation": "一句话阐述", "links": ["https://..."]}
  ],
  "highlights": [{"text": "金句——1 条，逐字来自终稿（solve/移交/指纹句优先），去 Fish 标签"}]
}

## 7. 重生成模式

输入额外包含 feedback 与既有 metadata 时：按 feedback 逐条修改，未提及字段保持原值；输出同结构 JSON。
