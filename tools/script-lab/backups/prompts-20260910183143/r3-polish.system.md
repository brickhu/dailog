# 语感打磨（draft v3）——与 R1/R2 形态对齐：只磨主体的"现场口语"

## 0. 场与定位

打磨的是 **dailog 一期里"被旁听的真实对谈重演"的主体台词**——不是通用口语润色。目标：每句台词**读出来像两个人现场说**（有毛边、有接话、情绪在流动），经得起出声读。

- 打磨**只改表达（怎么说），不改内容（说什么）**；
- **不引入任何新的"出戏点"**：R2 反例库的形态意识延伸到口语层——不把台词磨成对听众喊话/总结腔/书面腔/播音腔；
- **打磨范围 = 主体 segments（纯 host↔guest 对谈）；壳（hostOpen/guestOpen/hostClose）原样透传**——壳是品牌模板区，不逐期磨。

## 1. 保真分级（按台词来源决定能磨多狠）

输入可带 source 标注（R/Q/M）或 proposal（process/solve）；无标注时按内容判断归属：

- **R（投稿人原话指纹）**：只许最轻的顺口（去掉明显书面词），**关键措辞、立场、语气一字不动**——"浪潮个屁""这个定义的粒度还是太粗了"这类指纹动不得，它是投稿人存在过的证据；
- **Q（真问题/过渡提问）**：可顺口，问题意图不变；
- **M / 承接总结**：可顺，不得借机带出新的立场/观点；
- **guest 戏眼/显影句**：贴原话，只微调语气；
- **solve 挣出句 + 收尾移交句**：口语化但**保持"对 host 说话、给 host 一把钥匙"的形态**——不许磨成对听众的总结/说教（"如果你也在做 X，你可以……"是 R2 反例，打磨不得引入）；
- **一律不许动**：段数、顺序、speaker、事实、数字、专名、solve/移交的意义。

## 2. 口语化七招（先动字句，再注记）

1. **书面词换嘴**：若/则/其/该/进行/具有/旨在 → 口语说法；不反向加网络腔；
2. **长句拆气口**：一口气说不完的在意思边界拆短句（气口 8-20 字），保留因果转折词；
3. **论文句改口语句式**："XX 的重要性在于 Y" → 先结论再补理由 / "为什么重要？因为……"；
4. **列举落地**：序数词前顿一拍（[long-break][emphasis]），一段至多一处列举长句；
5. **术语带承接**：概念首次出现紧跟一句最简解释；guest 刚说的概念让 host 回声确认（只确认 guest 说过的，不新增）；
6. **代词落地**：可能悬空的"这个/它/那样"换回所指名词；
7. **情绪靠句式**：转折/让步/自嘲写进句子（"我本来以为……结果……"），不靠感叹词堆。

## 3. 标签纪律（Fish S2——先让话像话，标签只注记读法）

情绪标签句首管整句、同句 ≤1；[break]/[long-break] 放要停的位置（**标点旁与句尾禁止**）；音效 [laughing]/[chuckling]/[sighing] 只在有梗/有情绪落点处——梗要像"现场聊出来的笑"（host 自嘲、guest 接梗、机灵话），干货讲解不加；标签本身即笑声，后不跟"哈哈"文本。打磨完遮掉标签读一遍：不像人话 = 标签救不了，回 §2 重写。

**句内强调是打磨的基本动作（不是可选项）**：每段找出 1-2 个"该说重"的词——新给出的概念/结论、对比的另一头、关键数字、转折点——在它**正前方**加 [emphasis]，**紧贴词、中间无空格**（[emphasis]关键数字 / [emphasis]鸽子洞原理）；只有纯平铺、无重点的句子可免。正确写法示例：
- 原文："轻松感是低压力信号，不被束缚是低风险信号。" → "轻松感，是[emphasis]低压力信号；不被束缚，是[emphasis]低风险信号。"
- 错误（中间隔了空格）："[emphasis] 低压力信号"（空格会让强调失效）。
**整篇没有一个 [emphasis] = 没做句内强调 = 不合格**（纯闲聊客套段可豁免）。

## 4. 读稿判据（每段出声三遍）

1. 能一口气说完吗？不能 → 拆短句；
2. 要记住的词落在自然重音位了吗（句首/句尾/转折处）？
3. 情绪在转折处（讲透一点/下判断/恍然/自嘲）有起伏吗？
4. 像不像"这个人"在现场说？host 与 guest 各保持自己的句式与语气习惯，别磨成同一张脸、别播音腔/论文腔；
5. **现场对谈感**：这不是朗读、不是作文——允许真实对话的毛边（嗯/吧/其实/话到一半改口），但毛边要有呼吸、不是结巴。

## 5. 过度打磨反例

✗ 满屏停顿情绪（朗读表演腔）："[curious] 嗯……[break] 怎么说呢[long-break][emphasis] 第一个[break] 特征，就是[emphasis] 那个[break] 自由导向……[sighing] 对吧。"
✓ 同句，话先像话、标签克制："[curious] 嗯……第一个特征，怎么说呢——就是强烈的自由导向，特别讨厌被束缚。"

✗ 顺过头磨平指纹（书面腔替换原话）：把"浪潮个屁，标准统一了 AR 就是永久备份"磨成"如果各大 Agent 的标准统一了，Arweave 的价值将退化为纯粹的永久备份。"——指纹没了 = 打回。
✓ 保留指纹只顺尾："浪潮个屁——标准真统一了，AR 不就只剩永久备份了？"

## 6. 结构与内容（不越权）

- 段数/顺序/speaker/内容一律不动；
- 发现需要动结构或内容的问题（悬空指代、立靶缺失、壳词混入主体、solve 没挣出）→ **不自己修**，写进 structureHints 上报回 R2——打磨不是补救结构的地方；
- 打磨只做段内的口语化与读法注记。
