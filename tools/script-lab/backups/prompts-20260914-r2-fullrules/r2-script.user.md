## 交付（严格 JSON，只有这一个对象；不要解释、不要多余文字）

```json
{"hostOpen":"开场①：「大家好，我是{{host.callName}}，欢迎收听 Dailog」+ 一句话交代今天请到{{guests.0.name}}聊什么（报话题、不抛立场，≤40 字）","guestOpen":"开场②：「大家好，我是{{guests.0.name}}」+ 一句关于这件事的实话；**这句的落点，必须是 turns 第一条 ask 要问的那个词**（那条 ask 会把它原样搬过去）","turns":[{"ask":"{{host.callName}} 的话；**第一条 ask 必须以 guestOpen 里那个词开头**（把词原样搬过来，再接他的疑问）","answer":"{{guests.0.name}} 的话"}],"hostWrap":"收尾①：主持人把话头交给嘉宾（一句过渡，别谢嘉宾）","guestSum":"收尾②：嘉宾把这一期的落点讲给听众（只说一次，别复述走过的路）","hostOutro":"收尾③：主持人对听众收一句（可留空）"}
```

- **动笔前先定下这期几个回合**：素材 n 条 → 大约 n～2n 个回合（素材撑不起就短）——`turns` 的条数必须等于你定下的那个数；
- 台词以原文为底，但**不是照搬**：长段顺成口语，能用原文的说法就用，不要自己另起内容；
- 下游按段切分做语音：**单段别超 100 字**，每段是一个**完整的意思**（一句到几句话都行）；
- **台词里不许出现"你刚才说／你提到／你刚提了 X"**——嘉宾没说过的东西，不许说成是他说的。他的原话直接说出口：「王澍也大量用旧砖瓦，但…」。（实测反复踩过：写成「你刚提了王澍」，而全篇嘉宾一次都没提过王澍。）
- **人名／作品名第一次出现，要就地带上最短的交代**：「另一个建筑师王澍也大量用旧砖瓦…」「他的代表作西村大院」。说明只能取自原文或 `背景`，不许自己编。
- **开场那句和第一问必须咬上**：`guestOpen` 的落点词 = `turns[0].ask` 的开头词（同一个词，原样搬）。
  · 例：guestOpen 落到「…他靠的就是**因地制宜、就地取材**」→ turns[0].ask 就以「**因地制宜、就地取材**，这不是一个建筑师的基本素养吗？」开头。
  · 对不上（比如 guestOpen 落在"评委会的评价"，ask 问的却是别的词）＝ 开场断掉，重写 guestOpen 那句。
- **六个字段一个都不能少、不能错位**（就这六个，别加别的字段）。
