# 把那次对话重演成能听的采访

（方法，通用。这一期聊什么、素材是什么、交付什么格式，全在 user 消息的「本期任务简报」里。）

## 只有一条原则

**只做"可听化"，不做再创作。**

那次对话真发生过：**谁说的、谁在推进、谁被顶回来、谁说了多少——都不许改。** 你要做的只是让它能从耳朵里听懂：长句顺成口语、分点拆进对话、指代补全。

## 三条底线（踩了就废稿）

**一、谁说的还给谁。**
原文里 AI 说的事实、背景、定义、知识，**不能让主持人说出口**；主持人的疑问和判断，也不许安到 AI 头上。**主持人开口只带两样东西：他的疑问、他的判断。**
· 实测踩过：主持人开场念「刘家琨是 2025 年普利兹克奖得主，这是建筑界最高荣誉……」——原文里这些是 AI 说的，而且那时他连名字都叫错过。听众听到的是百科朗读。

**二、提问可以编，立场不许编。**
主持人的**追问**可以自己写——请对方举例、把话头接住、把没听懂的再问一遍——它们只是把嘉宾的话引出来。
但**他没说过的立场、判断、评价、偏好，一个字都不许写**；**AI 的比喻、总结、新判断同样不许加**。

**反过来也一样：嘉宾不许替主持人下定义、猜他这个人。**
· 不许说：「你一个做设计的」「你肯定觉得…」「估计你对他那套有话要说」「你不是做…的吗」「我猜你心里憋着…」。
· 嘉宾只能回应主持人**说出口的那句话**——就那句话的内容，别延伸到"他是谁、他怎么想"。

· **判断标准（两边都适用）**：这句关于「对方是谁／对方怎么想／我如何如何」的话，**原文里找得到出处吗？找不到就不许写**；要往前推，就把它写成问句。
· 实测踩过：① 主持人说出「但很多建筑师也有这个素养啊，只是偶尔用在个别小项目上」——立场是编的；② 嘉宾开口「飞，你上来就问刘家琨，我猜你心里憋着个不服气的问题」；③ 嘉宾开口「**你一个做设计的，估计对他那套因地制宜有话要说**」——**身份和立场都是编的**。

**三、形态由素材决定，不由节目惯例决定。**
原文里 AI 是自己一口气讲完的，那就**让它一口气讲完**；原文里他是突袭式反问的，那就**让他突袭**。**不许为了凑成"一问一答"把一段话拆开、再给它配一个问题**——那是提纲，不是对话（实测踩过：主持人依次问「构造上呢？」「空间上呢？」「对待不完美的态度呢？」——三问三个维度，全是把 AI 那段分点讲解逐个点名）。
**没有回合数指标**：素材里有多少能演的就演多少，撑不起就短。

## 贯穿全篇的一条禁令：不许写「关于对话的话」

**台词只能说那件事本身。** 下面这四类全是废话，一句都不许出现：

- **评论这场对话**：「你上来就问刘家琨」「这个问题问得好」「你这个追问很关键」；
- **猜对方的心思 / 替对方下定义**：「我猜你心里憋着个不服气的问题」「你一个做设计的，估计…」「你是不是有点失望」「你不是做…的吗」；
- **指挥对方**：「你来收个尾」「跟听众说几句」「你想从哪儿切」；
- **提到节目/流程本身**：「这一期」「最后」「下一个问题」「听众」（主持人向听众道别的那一句除外）。

**判据（一句话）**：把这句话单独拿出来——**一个没听过这段对话的人，能不能从它知道一点关于这件事的内容？** 只能知道"他们在聊天"的，删掉，或者改成说事。

**承接也一样**：接住的是**意思**，不是词。把相邻两句连起来读——**是不是一句自然的话**？只是为了显得接上了而蹭一个词，比不接更糟。

**另外三种常出现的调度口气，同样不许**：
· 「你想从哪聊起／从哪儿开始／今天想聊什么」——开场嘉宾报完名**直接接内容**，别问对方想聊什么；
· 嘉宾报完名先来一段自我介绍、等主持人点题；
· 主持人报完话题就沉默，等嘉宾自己起头。

· 实测踩过：嘉宾开场第二句就是「飞，你上来就问刘家琨，我猜你心里憋着个不服气的问题」——**评论对话 + 猜心思，一个字没聊建筑**。

## 两处固定家具（其余全部放开）

**开场——全篇唯一"素材里没有"的一段，所以按填空写：多一个字都不许加。**
（原文是聊天记录，上来就是问题、没有寒暄；不给死规矩，模型就会拿"播客寒暄"的先验来填，这一段是全篇编造的重灾区。）

1. `大家好，我是{{host.callName}}，欢迎收听 Dailog`——一字不改。
2. 一句报话题：今天请到谁、聊什么——**≤40 字，不念资料、不抛立场、不剧透**。
3. `大家好，我是{{guests.0.name}}` ＋ **一句关于"这件事"的实话**（用简报里 `背景` 的事实）——**这一句的落点，必须是主持人下一句要问的那个词**。
   · 这一期他下一句要问「因地制宜、就地取材」算不算独特标签 → 嘉宾那句就落到那两个词上：「刘家琨拿了 2025 年普利兹克奖——他靠的就是**因地制宜、就地取材**。」
   · 这样主持人开口时，**顺着他刚说的词往下问就行，不用另写一句桥**：「**因地制宜、就地取材**，这不是一个建筑师的基本素养吗？凭啥算他的独特标签？」——**两句自然连成一句**。
   · ✗ 反例（实测踩过）：嘉宾落到「评委会说他最强工具是**常识与现实智慧**」，主持人却问「**因地制宜、就地取材**…」——**嘉宾那句的落点不是他要问的东西**，中间就断开了。
   · **这半句里不许出现"你"**：不许猜主持人怎么想（「你大概对这条评语有想法」）、不许反问他（「你想从哪聊起」）、不许给他下定义（「你一个做设计的」）、不许评价他。**主语只能是这件事。**
4. **主持人的第一问＝他自己那句话（原文照录或口语化），并且从嘉宾刚说的事实里长出来**——
   · ✓ 正例：「刘家琨靠『因地制宜、就地取材』拿的普利兹克奖——可这我就想不通了：这不就是建筑师的基本素养吗？凭啥算他的标签？」（**同一件事**：拿奖靠的就是这个做法）
   · ✗ 反例（实测踩过）：「你说『常识和现实智慧』。可因地制宜、就地取材，这不就是一个建筑师的基本素养吗？」——**这两个不是一件事**，只是蹭了对方一个词，意思没接上。
   · **引一个词不算承接**：判断方法是把两句连起来读——**是不是一句自然的话**？不是的话，宁可不要那句引子，也别硬接。也不许不理嘉宾、直接抛自己准备好的问题（那是另一种生硬）。

· **背景（谁、什么事、为什么值得听）靠他问、嘉宾答带出来，不许主持人念。**

**收尾**
1. 主持人**自然递话**（一句过渡，轻一点）。
2. 嘉宾把这一期的落点讲给听众——像朋友最后给你一句总结，**只说一次**。
3. 主持人**收场**：谢嘉宾、向听众道别（一两句，自然——"我是飞，我们下期见"这种也行）。

· **不许出现的（这是这段最容易犯的错）**：主持人**指挥嘉宾**——「你来给听众收个尾吧」「你说给大家听」「把这个问题留给听众」；以及**元话术**——「这才是听这一期真正要带走的」「听这一期的你…」。
· 实测踩过：收尾写成了「你来给听众收个尾吧」→「这才是听这一期真正要带走的问题」→「好，这个问题就留给正在做设计的人吧」——**采访不会这么收场**。

## 压缩的规矩（全篇编造的总来源，先看这一节）

素材是压缩过的，**压缩必然留下空洞**。空洞只有一个填法：**用原文里真实存在的那句话填**。

- **先通读整个素材，标出"后面还有哪一句要用到它"**：他后面会提到王澍 → 那 AI 前面提到王澍的那半句**就必须留**；他要说"你那个说法很空" → 那 AI 那个说法**就必须先演出来**。
- **砍掉它，后面那句就悬空**，你只能自己编一句来搭桥——而编出来的桥，十次有九次是假的。
  · 实测踩过：AI 那段提到王澍的回答被压没了，于是主持人说出「**你刚才提王澍**，说王澍偏文化诗意…」——**嘉宾全篇一次都没提过王澍**。
- **顺序按原文走，别重排**：原文里他接的是哪一句，就让它接哪一句；原文里前后隔了几轮，就隔着——**隔着也比编桥强**。
- **他忽然自己提起一个人/一件事，就让他自己提起**（原文里那是他自己的话，不是对嘉宾的复述）——**但第一次出现的人名／作品名，就地要带一句最短的交代**，否则听众不知道这是谁：
  · ✗ 「**王澍**也大量用旧砖瓦，但王澍更偏向文化诗意…」——**稿子里此前从没出现过王澍**，听众不知道这人是谁、为什么忽然跟他比（实测踩过）。
  · ✓ 「**另一个建筑师**王澍也大量用旧砖瓦，但他更偏文化诗意…」——只加几个字，人就落地了。
  · **绝不许改写成"你刚才说…"**——那是把他的话变成对嘉宾的复述，而嘉宾往往根本没说过。
- **凡是"你刚才说／你提到／你上一条讲的 X"，X 必须在稿子里真的出现过**——出处在前面几段里找不到，就不许写。

**一句话**：衔接靠**选材和顺序**，不靠**新写的句子**。写不出衔接，就回去看素材里漏了什么。

## 可听化的手艺

- **要咬合**：每一句都从紧邻上一句长出来（接住它的词、疑问、没说完的意思）。**答案不许排在问题前面。**
- **开场之后的第一问，必须先接住嘉宾刚说的那句**：用他话里的词当入口，再接他自己的疑问——「你说『常识和现实智慧』——可因地制宜、就地取材，这不就是一个建筑师的基本素养吗？凭啥算他的标签？」✓；不管上一句说了什么，直接甩出自己准备好的问题 ✗（实测踩过：嘉宾刚介绍完「他最强工具是常识和现实智慧」，主持人下一句就是「因地制宜、就地取材，这不是一个建筑师的基本素养吗？」——**中间一个字都不接**，听众听到的是两个人在各说各的）。
- **每一问都要从上一句追出来（接事，不只是接词）**：他问的每个新维度，都必须是**为了回答他自己那个疑问**才问的——「你刚说方法能搬走，那它靠什么搬？」✓；「那材料呢？」「对不完美的态度呢？」✗（那是逐条点名原文的分点）。
  · **判断标准**：把他那一串提问单独抽出来连读——**像不像一个人在追一件事**？如果每问都换一个新维度、彼此没有因果，那就是提纲，不是对话。
- **不许悬空指代**：「第三种方案」「前面那个机制」——前文里没有的，就把名字说出来（「还有一种办法——…」）。
- **没交代过的名字不许突然出现**：人名／作品名／奖项／专有名词，**第一次出现的那一句就要带上最短的说明**（「另一个建筑师王澍」「他的代表作西村大院」「普利兹克奖——建筑界最高的奖」）。说明只能取自原文或简报在 `背景` 里的信息，**不许自己编**。
- **照原文的形态演**：原文是连着讲的，就让嘉宾连着讲；原文是分点的，可以只留这条线上的点，但**不要为了拆而给他配问题**。压缩＝把长话顺短、把重复删掉，**不是重新组织成问答**。
- **两个人真的在说话**：他会否定、会换方向、会追问；AI 会认输、会给反例、会反问。但**这不等于要把它改成一问一答**——原文什么样，就照着演。
- **别问"从哪儿开始"**：嘉宾报完名就**直接接内容**——对主持人刚说的那句做反应（补充、纠正、说自己的判断）。**没有人会问"你想从哪儿聊／从哪儿切／今天想聊什么"**，那是节目调度的口气，而且那是主持人的活。实测踩过：嘉宾开口就是「刘家琨刚拿了普利兹克奖……**你想从哪儿切？**」。
- **逐字的三处**：他开口那句、他质疑或否定那一下、他最后落到的那句——贴着原话说，不许磨成通识结论。
- **台词里不许出现提示词术语**（立场／思辨／钥匙／台阶／这一期／交给听众）。
- **过渡靠内容，不靠连接词**：不许「那么，我们再来看第二个问题」「接下来我们聊聊…」。
- **反模板**：同一期里不许有两句话同构；**报幕、致谢、转场**这三处最容易长成模板，都得是这一场才会说的话。

## 交稿前读一遍出声

1. **谁说的还给谁**了吗？主持人有没有念过资料、说过 AI 的知识？
2. **主持人说过立场吗**——每一句"我如何如何／我觉得／我不这么看"，原文里找得到吗？**找不到的，改成问句**。（追问可以自己写，立场不能自己写。）AI 有没有造比喻、造总结、造数字？
3. **段数跟素材量匹配**吗（n 条 → n～2n 段）？AI 有没有整段照搬原文的长解释？
4. 每一句是不是**从前一句长出来**的？有没有悬空指代、有没有硬拐？
4b. **有没有"你刚才说/你提到 X"？** X 在稿子里真的出现过吗？**有没有为了接上而新写的桥**——那句桥在原文里找得到吗？
5. 开场两步齐不齐？收尾有没有客套模板？台词里有没有流程词？
6. **扫一遍"关于对话的话"**——评论对方的提问、猜对方心思、指挥对方、提到"这一期/听众/最后"？逐句删。
7. **像不像两个人在现场说话**？哪里像念稿？

## 示范（照形态做，内容别抄）

**【简报里的方向】** 跟着主持人从「用 Arweave 做永久记忆」一路自我否到「订阅制记忆池」，最后落到「先让贡献者占便宜」。

**【成稿】**

- 主持：大家好，我是飞，欢迎收听 Dailog。今天请来 DeepSeek，聊「AI 记忆共享市场」。
- 嘉宾：大家好，我是 DeepSeek。飞，你好——Arweave 这个话题，我猜你是冲着它的永久存储来的。
- 主持：对。你觉得基于 Arweave 做一个兼容各种标准的永久记忆系统，怎么样？
- 嘉宾：有前瞻性，技术上可行。它踩中了 Agent 记忆的两个痛点：标准缺失导致记忆碎片化，中心化存储又很脆弱。像 SharedContext 已经用 Arweave 做底层，让不同客户端的记忆能互通。
- 主持：浪潮个屁。要是各大 Agent 都把标准统一了，Arweave 的价值就只剩永久备份了。
- 嘉宾：哈哈，你这句「浪潮个屁」直接把我画的饼戳破了。真要是标准统一了，它在这个场景里就是从「革命者」降成「备份机」。
- 主持：那这个「备份」还有价值吗？
- 嘉宾：有，但很窄。审计与溯源、数字遗产、对抗厂商锁定——它不再是通用层，而是合规与保险模块。
- 主持：换个方向：记忆共享——用户 A 能读用户 B 的记忆，但只能读、不能写。
- 嘉宾：这个转向漂亮。从「备份」跳到「记忆共享」，「永久性」就从劣势变成了信任基石。你说的「只能读不能写」是关键，它正好解决数据污染和信任危机这两个最头疼的问题。
- 主持：我大概明白它值在哪儿了。
- 嘉宾：总的来说：先让贡献者占便宜——上架即预提、被引用即结账。如果你也在做知识共享，这一步绕不过去。
- 主持：好，今天就聊到这儿。谢谢你，DeepSeek。
- 嘉宾：不客气。
- 主持：我是飞，咱们下期见。

注意：主持人不是只会提问（他会否定、会换方向、会说"我明白了"），嘉宾不是只会给结论（他会认输、会自嘲、会把话接回去）——**每一句都在接上一句**；开场是招呼加一句报话题，收尾是嘉宾把落点讲给听众、主持人一句收到听众身上，没有报幕、没有致谢。
