# OV 概要（Overview）

> **索引**：主文档 `SKILL.md`（定义/触发见主文档）｜ 步骤 OV-STEP-1..3 ｜ 节码 OV-FLOW / OV-IN / OV-GATE / OV-OUT / OV-ERR
> 命令统一带会话环境（`--env <环境>` 或 `DAILOG_ENV`）。

**OV-FLOW 流程 / 原则 / CLI 调用逻辑**
```
OV-STEP-1 环境确认门（强制，见 SKILL.md「会话初始化」ENV-GATE）：选环境 → auth-status，未配对先引导 login——未过门不展示概要
OV-STEP-2 pnpm editor overview → 拉取：环境/网站/账号 + 采集·脚本·语音·节目 四管道待处理与共计 + 待处理选项
OV-STEP-3 按「工作台概要」模板展示（见 OV-GATE）；用户选号或输入入口关键词进入对应流程
```
原则：概要只读展示 + 菜单导航，不自动执行任何流程。计数口径：
- ① 采集 待处理 = 服务端 submitted 队列（投稿已提交、未采集）；共计 = 服务端投稿全量
- ② 脚本 待处理 = 本地草稿有 dialogue.json、无终稿 script.json；共计 = 已采集投稿全量
- ③ 语音 待处理 = 本地草稿有 script.json、未合成 final.m4a；共计 = 脚本全量
- ④ 节目 待处理 = 本地草稿有 final.m4a、未发布（终态 published/rejected/republished 不计）；共计 = 已发布节目数
- 待处理选项 = **按流水线阶段（采集→脚本→语音→发布）生成的动作菜单**（猜测下一步意图）：有积压的阶段才出现
  （如「批量采集 N 条投稿」「处理 N 条已采集未出脚本」「合成 N 条已出脚本未出语音」「发布 N 条已合成未发布」）；
  没有待处理则不显示该块；具体投稿用入口关键词（采集:{ID}/脚本:{ID}/TTS:{ID}/节目:{ID}）定位
- 其他功能 嘉宾 = /v1/editor/guests；声线就绪 = /v1/editor/guests/voice-samples 按 guestId 去重；
  播放列表 = /v1/editor/playlists（期数 = episodeCount 求和）；下线申请 = /v1/editor/episodes/removal-requests（缺省 pending）

**OV-IN 输入规范与依赖**
依赖会话已初始化（环境 + 配对）；命令无额外参数。

**OV-GATE 确认门选项与输出模板**
**输出模板（工作台概要——概要与入口导航，非选号菜单）**（回复正文展示，见 RULES-9 呈现通道）：

```
**工作台概要**
- 环境：{环境名} ({apiBase})
-  网站：{siteUrl}
-  账号：{编辑邮箱}

该环境共计 {N} 条投稿，共计发布 {N} 条节目；
___

- 采集：**{n}** 条待处理，共计 {N} 条；输入「采集」查看采集列表，「采集:{ID}」采集对话；
- 脚本：**{n}** 条待处理，共计 {N} 条；输入「脚本」查看脚本列表，「脚本:{ID}」进入脚本审核和生成流程；
- 语音：**{n}** 条待处理，共计 {N} 条；输入「TTS」查看语音列表，「TTS:{ID}」进入语音生成流程；
- 节目：**{n}** 条待处理，共计 {N} 条；输入「节目」查看节目列表，「节目:{ID}」进入节目/发布流程；

其他：
· 嘉宾：**{n}** 位（声线就绪 **{m}** 位）——入口「配置嘉宾」「配置嘉宾声线」
· 播放列表：**{n}** 个（共 **{k}** 期）——入口「配置播放列表」
· 下线申请：**{n}** 条待审批——入口「节目」
· 更多入口：「批量采集」「重新生成:{ID}」「配置」

```

**确认门选项（选号菜单——统一选号格式见 RULES-10；①-④ 与「其他」属概要，不参与选号）**：
- **待处理选项（按流水线阶段生成，一项一行）**：
  `[1] : 📥 批量采集 {N} 条投稿`（采集待处理 > 0）
  `[2] : ✍️ 处理 {N} 条已采集未出脚本`（脚本待处理 > 0）
  `[3] : 🔊 合成 {N} 条已出脚本未出语音`（语音待处理 > 0）
  `[4] : 📦 发布 {N} 条已合成未发布`（节目待处理 > 0）
  ……有积压的阶段才出现（采集→脚本→语音→发布顺序）；没有待处理则不显示该块
- 也可直接输入入口关键词（「采集:{ID}」「脚本:{ID}」「TTS:{ID}」「节目:{ID}」「配置」等）触发对应功能

**OV-OUT 输出物存放与命名标准**
无落盘产物。

**OV-ERR 错误处理**
未配对 / 端点不可达 → 计数显示 0，引导 login（auth-status 检查）；环境选错 → 按会话初始化重选。
