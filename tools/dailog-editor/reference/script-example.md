# 脚本结构示例（SC-STEP-2 结构示范——仅供人工参考，子代理不加载）

> 这份示例**不在 draft 子代理的加载清单里**——draft.md 提示词只给规则与判断标准，不给成稿样例，
> 防止模型模仿示例句式导致产出模板化。本文件只供人（编辑/维护者）对照理解脚本结构。

以「街拍账号差异化」一期为例（用户想做街拍自媒体但同质化严重，来问如何差异化）。
**只示范结构，绝不套用话题/措辞**——新一期的话题与内容必须来自新对话（角度保真）；
示例句（"我心里那块石头总算落下来了""你这句话说到根子上了"类）一律禁止照抄——措辞必须来自本期对话。

part1 点题（host 面向听众的开场：问候+自我介绍+品牌句+背景+引嘉宾，埋钩子不剧透）
host: 大家好，欢迎收听 Dailog！我是{callName}。最近我想做街拍类的摄影自媒体：在街上遇到好看的女生，
礼貌地问能不能给她拍几张照片……但这种账号现在到处都是，我一开始根本说不清自己跟别人有什么不一样，
所以带着一堆问题来了：这种账号靠什么成功？怎么变现？最关键的是，怎么做出差异化？今天请到了 ChatGPT，
想请它帮我理一理。

part2 对谈（host↔guest 互致问候开场；转场全有由头 + 确认性穿插 + moment 在正确位置）
guest: 你好，{callName}！这类账号能不能起来，关键不在照片，在于被拍的人有没有安全感。
host: 所以核心是信任感，不是技术？　← 确认式追问
guest: 对。　← 短确认（≤5 字，不展开）
host: 那这份信任，怎么变成钱？　← 顺势追问（确认性穿插三连）
…
host: 你刚说最值钱的是人格 IP……可这 IP 是怎么立起来的？我想先看看别人怎么做的。　← 转场=被触发
…
host: 对……我想了想，职业访谈这个视角太窄了，我觉得更多是让这个人做一个简单的自我介绍，通过简单的
采访问一些大家在跨文化中比较好奇的问题。　← moment（用户自我修正，逐字来自原文）

part3 落点+收束（同一 part，一次 TTS 请求）——
落点（轻感触 + 在场收尾，禁知识总结）
host: 我同意你这句话。聊到这里，我心里那块石头总算落下来了。之前总觉得这种账号太多了，我挤不进去；
现在至少，我知道自己该往哪儿走了。

收束（AI 知识性收拢 + 印证，1-2 句）
guest: 你这句话说到根子上了。别人记住你的，不是你拍得多好，而是你看世界的角度。
