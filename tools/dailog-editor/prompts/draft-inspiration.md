# 启发（inspiration）——「换角度看」：写作结构 + 好坏判断标准

# 写作结构（本维度叙事——通用机制见 draft.md 4.1-4.3，此处只列维度特有的内容形态）
- **点题背景形态**：一直想着的旧视角——只露动摇/开放（"总觉得这个想法有点站不住"），不揭反转。
- **moment 形态**：视角碰撞的瞬间——用户被激发，一句话能说清"想法怎么变了/看世界的角度变了"（用户亲手说出，不是 AI 塞）。
- **落点感受**：换个角度看——轻感触。
- **收束形态**：把新视角的意义说透/期许。
- **维度红线**：知识纠偏不是启发（归认知）；视角转换必须发生在用户身上（AI 的精彩观点不算）。
> 通用机制：开场/转场/互动/收尾回合/落点模板见 draft.md 4.1-4.3。

# 好的判断标准（教判断，不教句子——判据不是可抄的措辞）
- 点题只露旧视角的动摇（"总觉得这个想法有点站不住"），不揭反转——moment 留到对话里
- 反转由用户亲手说出（"所以我要找的不是'少'，是'少到只剩一个'？"），不是 AI 塞结论
- 对谈有用户主动质疑/追问/重新表述（"等等……"），不是单方面附和
- 落点是具体的转变（"差别不在数量，在'能不能一句话说清我是谁'"），不是空泛"我学到了"
- AI 长段控制：guest 超两句必拆段 + 停顿，host 短接

句子级微示例（检查标准，不是素材——只示范形态，措辞必须来自本期对话）：
- host 附和：短词 + [break]（"嗯……[break] 对。"），不重复 AI 的话
- host 落点："差别不在{旧维度}，而在{新维度}。"

# 不好的失败模式（知道什么是不好）
- 编造用户经历/提问（红线——不尊重用户，禁）
- 点题直接揭反转（"直到 ChatGPT 告诉我…"）——剧透 moment
- 视角转换是 AI 给的结论（"你看苹果、看微信都是极简的"）——用户没有亲身碰撞
- host 只附和（"有道理，我以后就做减法"），无主动质疑/追问/重新表述
- 落点空泛（"做 APP 要少而精"），不是"看世界的角度变了"的具体呈现
