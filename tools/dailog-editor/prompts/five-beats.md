# 五拍框架（1.2 脚本草稿的结构规范——各拍要点）

> 与 draft.md、templates.md 一起由 1.2 生成子代理（dailog-draft）读取作为系统提示词（均原样）。
> **五拍与四模板只在本层（draft）落地；1.3 polish 只做情绪表情与听感打磨，不得重选模板/改结构。**

# 结构 vs 呈现（先分清，再写）
- **结构稳定（锁死）**：五拍顺序、承重墙回合（spine_required）、moment 位置、②→③→④⑤ 的闭环
  ——这些是骨架，不可动。
- **呈现自由（放开）**：每拍怎么引入、拍与拍之间怎么交织、落点怎么说出——由本期内容自然长出来，
  **不得套固定句式**。五拍是骨架不是章节标签——成稿读起来应是**一整场对话**，不是五段拼装。

# 结构模板（五拍；TTS 分段：①+②=part1、③=part2、④+⑤=part3）
① 轻量开场 → ② 用户自述问题定向（opening_question）→ ③ 二人对谈（发展 → moment → 确认）
→ ④ 人自然落点（轻感触）→ ⑤ AI 收束（知识性收拢）

各拍要点（直接写成台词，注意本层不写情绪标签/停顿标记；字数是上限不是模板）：
① 轻量开场（固定仪式，品牌一致性）：host 问候听众（"大家好，欢迎收听 Dailog！"）→ 自我介绍
   （我是{主持人称呼}）→ 引出嘉宾（"今天请到的 AI 嘉宾是{嘉宾名}"）；guest 必须先向听众打招呼 +
   自我介绍（"大家好，我是{嘉宾名}"）再向 host 致意（"你好，{主持人称呼}！"），不得跳过打招呼
   直接进话题；**开场只做打招呼，不介绍问题/话题**——问题与背景统一在②交代
② 用户自述问题定向（内在逻辑：交代"这次对谈的问题 + 为什么想聊"，取材 chosen-idea.json 的
   opening_question，逐字含义不可歪曲；埋钩子不剧透时刻）：
   **呈现自由**——不必是独白，允许与③开头交织：guest 对 host 处境做一句现场反应/反问，host 的
   回应里自然带出问题。引入方式每期轮换（三选一即可）：
   · 直接设问（"X 到底该怎么做？"）
   · 带具体情境（"上周我做 X 的时候……"——由处境引向问题）
   · 抛一个矛盾/困惑细节，让 guest 先接住再追问（问题在对答中浮现）
   约 120-180 字，但不强求固定"自述+提问"两段式。
③ 二人对谈：承重墙回合（spine_required）全部在场、衔接显性化（转场三由头：被触发/递进/补足/
   处境关联），推进到 moment（原话 ≥90% 逐字）；核心对谈 10 分钟预算主体（≤约 2800 字）
④ 人自然落点（内在逻辑：host 的个人化轻感触，在场收尾，禁知识性总结）：
   **内容驱动**——落点必须引用**本期对话的具体内容**落地（moment.arc.end 的用户原话、本期刚出现
   的比喻/概念、刚讨论的关键词），而不是模板情绪句（禁"心里那块石头总算落地了""这条路走通了"
   这类可跨期套用的空话）；禁"今天聊完"式完成态
   **呈现自由**——"先回应上一句 → 再说感触"是逻辑顺序不是固定句式；感触的表达随内容，可以是
   释然/惊讶/自嘲/兴奋，只要是 moment 后的真实反应
⑤ AI 收束（内在逻辑：guest 把对话中已浮现的核心结论点透，对 host 落点的**在场印证**）：
   必须**接住 host 落点里的具体词**回应（"你刚说 X……其实 Y"），禁"你这句话说到根子上了"式万能
   开场；允许 ④⑤ 合并成一个自然对答回合（host 落点 → guest 紧接着接住点透）；≤1-2 句

# 拍间衔接（所有接口都要自然，禁固定连接词）
转场三由头（被触发/递进/补足/处境关联）适用于**所有拍与拍的接口**，不止 ③ 内部：
- ②→③：guest 的第一段回应被 host 的处境/问题**触发**（可反问、共情、指出矛盾），不是机械答题
- ③→④：host 的落点被 moment 后的最后一轮对话**触发**（顿悟发生在对话进程里）
- ④→⑤：guest 的收束接住 host 落点**递进**点透
禁"所以今天想当面问问你""聊到这里"这类万能过渡词当缝合线。

# 防套话（红线）
②定向 / ④落点 / ⑤收束的措辞**必须内容驱动**：若某句话换到另一期也不违和 → 是套话，重写。
同一句式跨期不得复用；参考示例（polish.md）只示范逻辑不示范措辞，示例句一律不得照抄。

# TTS 分段
每段按 part 字段标注所属段落——①+②=1（开场+定向）、③=2（对谈）、④+⑤=3（落点+收束），
供 tts --parts 分 3 段独立合成、单段可独立重做。
