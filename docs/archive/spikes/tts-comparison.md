# Spike 决策记录：TTS 供应商对比与选定

> 日期：2026-08-02 · 状态：**决策定稿 —— TTS 供应商 = Fish Audio**
> 配套：ARC §3.3（管线）· 计划 2 Task 2（集成验证）

## 决策过程

**核心刚需**：Instant Voice Cloning（即时克隆）——用户注册录 10-30s 样本即得克隆音色。评估维度：克隆质量（相似度+自然度）> 即时克隆模式（A 零样本按需 / B 预注册复刻）> 价格 > 多说话人（非刚需，管线有 ffmpeg 分批兜底）。

**候选对比**（价格为 2026-08 调研值，最终以实测账单为准）：

| 候选 | 即时克隆 | 合成单价 | 每期成本（10 分钟≈3000 字） | 关键结论 |
|---|---|---|---|---|
| **Fish Audio** ✅ 选定 | A 零样本按需 | $15/百万 UTF-8 字节（中文 1 字 3 字节） | ≈¥0.97 | 零样本按需、多说话人原生、重录即时生效 |
| 讯飞一句话复刻 | B 一句话训练 ¥2.3/次 | ¥1.15/万字符（促销） | ≈¥0.7+训练 | 价格杀手，但预注册制 + 促销价待确认 |
| 火山声音复刻 | B 5 秒级复刻 | ~¥5/万字符 | ≈¥3 | 槽位费/年费复杂，认证门槛待确认 |
| MiniMax 快速复刻 | B ¥9.9/音色 | HD ¥3.5 / Turbo ¥2 每万字符 | ≈¥1.2-2.1 | 临时音色 7 天限制 |
| CosyVoice 百炼 | B 复刻制 | ¥2/万字符（汉字×2） | ≈¥1.2 | 复刻费待确认 |
| 硅基流动 CosyVoice2 | A references 按需 | ~¥1-2/万汉字 | ≈¥0.3-0.6 | 有下架传闻，不稳 |
| Azure | ❌ 非即时（CNV 需审批+训练 $5000+） | $16/百万字符 | — | **排除**：克隆不满足刚需 |

## 选定理由

1. **零样本按需即时克隆**（模式 A）：无需音色预注册/训练/审核环节，用户录音样本随请求携带——**重录即时生效**，与产品流程（注册录 10-30s）完美匹配
2. **多说话人原生支持**：一次调用可混排克隆音色 + 固定音色（管线优先尝试，超限分批兜底）
3. 单价中游（¥3.2/万汉字），低于 MiniMax/CosyVoice/火山，高于讯飞促销价
4. 单一供应商集成成本低

## 备选切换预案（触发条件：成本超标 / 音质不达标 / 合规问题）

| 触发场景 | 切往 | 备注 |
|---|---|---|
| 每期成本敏感（有量后） | 讯飞一句话复刻 或 自部署 CosyVoice2 | 自部署需 GPU（Apache-2.0 可商用，与百炼同源） |
| 音质不达标 | MiniMax / 火山 实测对比 | — |
| Fish 政策/价格变动 | 任一候选 | 管线 TTS 层保持供应商抽象（ARC §3.3） |
