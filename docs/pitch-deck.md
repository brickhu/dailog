# Pitch Deck — 10 页投资人演示大纲

> 状态：初稿（2026-08-03）。配套文档：[pitch-narrative.md](./pitch-narrative.md)（叙事与讲稿）· [MRD.md](../MRD.md)（市场与商业）· [PRD.md](../PRD.md)（产品）· [ARC.md](../ARC.md)（技术）
> 使用说明：15 分钟讲述 + 10 分钟 QA 的标准形态；10 分钟路演版砍掉 P3/P7 细节。每页标注「要说服什么」「关键台词」「视觉」「时长」——台词原文出自 pitch-narrative.md。

---

## P1 封面 — 一句话 + 类比

- **要说服什么**：30 秒内记住我们是谁
- **页面内容**：产品名 + 一句话 + 类比 + 品类名
  - 一句话：把每个人和 AI 的对话，一键变成他自己的播客
  - 类比：剪映之于视频 = dailogues 之于播客
  - 品类名：Personal AI Podcasting / 个人 AI 播客
  - 视觉：一期真实节目的播放器截图（不是 logo 大图）
- **关键台词**：不做开场寒暄，直接说这句话
- **时长**：30 秒

## P2 世界变了 — 宏观转变

- **要说服什么**：一个被所有人忽略的结构性变化正在发生
- **页面内容**：
  - 2026 年，普通人每天产出最有价值的文字，是写给 AI 的（研究/构思/写作/倾诉）
  - 对话正在替代日记、草稿、与同事的讨论
  - 数字：ChatGPT/Claude/DeepSeek 的对话总量增速（引用公开数据即可，不编造自家数据）
- **视觉**：时间轴或增长曲线 + 一张「对话即产出」的示意
- **关键台词**：你的文字产出不再只是写给人看的
- **时长**：1 分钟

## P3 矛盾 — 内容被困在聊天框

- **要说服什么**：现状的所有分享方式都失效，痛点真实且普遍
- **页面内容**：
  - 有价值的对话躺在剪贴板/历史里
  - 分享 = 截图 / 贴长文 / 分享链接——没人读完
  - 对话是口语的、进行时的，却被锁死在文字形态
  - 无法订阅、无法重听、无法被发现
- **视觉**：三张「现状分享」对比图（截图墙、长文墙、链接）
- **关键台词**：对话明明应该被「听」，却只能被「读」
- **时长**：1 分钟

## P4 洞见 — 音频是对话的天然容器

- **要说服什么**：我们看到了正确答案，且有人在验证；我们做的是形态，不是工具
- **页面内容**：
  - 播客 = 互联网最后一个开放分发协议（RSS：不锁平台、可订阅、可带走）
  - NotebookLM Audio Overview 已证明「AI 对话式音频」有人听（2024-25 病毒式传播）
  - 但它缺两样：**你的声音** + **你自己的真实对话**
  - 差异表（NotebookLM vs dailogues）：别人的材料 → 你自己的对话；固定 AI 主持 → 你 + AI；听完即止 → 频道 + RSS 进播客生态
  - **形态命名**：真人 AI 对谈（AI-native talk shows）——不是播客工具，是新形态的孵化器
  - **注脚（剪映类比，降级使用）**：剪映之于视频 = dailogues 之于对谈节目——但剪映的形态已被抖音验证，我们要同时证明形态存在 + 工业化生产
- **视觉**：左右对比表（直接搬 MRD §4.1）+ 形态命名一行
- **关键台词**：NotebookLM 做的是别人的材料，我们做的是你自己——这是「真人 AI 对谈」形态的起点
- **时长**：1 分钟

## P5 Demo — 现场演示（本场最重要的 3 分钟）

- **要说服什么**：管线是真的、成品是能听的
- **演示脚本**（见附录 B）：
  1. 打开 Claude/DeepSeek 的一段真实对话 → 扩展一键采集（10 秒）
  2. 工作台：质量门通过 → 一键润色（流式出稿）→ 手动改两句
  3. 生成：安全审核 → TTS 进度 → 试听（**放 30 秒成品音频，放完再继续讲**）
  4. 发布 → 打开播客客户端展示 RSS 订阅成功
- **视觉**：真机/录屏，提前排练 5 遍；音频提前备好降级方案（现场无网时放录屏）
- **关键台词**：什么都不说，让成品自己说话
- **时长**：3 分钟

## P6 为什么是现在 — 三条成本曲线交汇

- **要说服什么**：窗口期真实存在，今天不做明天成本优势就没了（错，反向——窗口在打开，不是关闭；语气是「第一次成熟到可以产品化」）
- **页面内容**（放实测数字，出处 ARC §3.3）：
  - TTS 成本：一期 10 分钟 ≈ ¥0.97（$15/百万 UTF-8 字节）
  - LLM 润色：一期 ≈ ¥0.04（DeepSeek）
  - **单期边际成本 ≈ ¥1**；语音克隆两年降一个数量级，开源路径兜底（CosyVoice）
  - 播客消费侧：中文播客生态增长，小宇宙/Apple Podcasts 在等供给
- **视觉**：三条成本曲线图 + 大数字卡片
- **关键台词**：技术第一次成熟到「个人播客」可以产品化
- **时长**：1 分钟

## P7 产品 — 全自动管线

- **要说服什么**：不是一个单点工具，是一条完整价值链；顺手讲清平台覆盖
- **页面内容**：
  - 输入：浏览器扩展在用户登录态采集本人对话（Claude/DeepSeek 首批，ChatGPT/Gemini/Kimi/豆包/通义按级扩展）——**真实性 = 登录态，无需分享链接**
  - 加工：质量门 → 润色（可编辑、流式）→ 内容安全门（拒绝不扣费）
  - 输出：克隆音色（你）+ 固定音色（AI）→ 片头片尾 → 播放页 + RSS + MP3
  - 每人一个频道 `dailogues.com/@username`
- **视觉**：管线流程图（ARC §3 简化版，一图讲完）
- **关键台词**：用户只需要做两件事——录 30 秒声音，点一下采集
- **时长**：1 分钟

## P8 壁垒与大厂盲区

- **要说服什么**：大厂不会做，且我们越做越深
- **页面内容**：
  - 三件套：「真实对话 × 克隆身份 × 开放分发」——大厂各有碎片、无人连接
  - 推演：OpenAI 选型平台内短视频（Stories）；Google 只做学习工具（NotebookLM）；TTS 厂商无管线无分发
  - 合规敏感区：公开克隆用户声音并分发，大厂不敢碰——我们的架构天然合规（本人录音 = 同意、双审核门、举报下架）
  - 迁移成本：频道、订阅者、已发布节目都在这里
- **视觉**：三列「大厂碎片 vs 我们」对比图
- **关键台词**：我们做的不是他们没做的事，是他们不敢做、也架构上做不了的事
- **时长**：2 分钟

## P9 商业模式与单位经济

- **要说服什么**：单位经济健康，免费层烧得起，增长自带
- **页面内容**：
  - 按脚本字数计费：成本（LLM + TTS）随字数线性，定价与成本对齐；脚本上限 5000 字封顶
  - 免费首期 0 扣费（完整体验）+ 润色免费（获客漏斗，单次 ¥0.04）
  - 按期按字数付费（基本盘）→ 高频用户包月（¥29-49 参考区间）
  - 成本表：单期 ≈ ¥1 边际成本；基础设施免费化（CF/R2 免费 + Railway 约 $10-25/月）
- **视觉**：单位经济卡片（收入/成本/毛利一列排开）+ 定价阶梯图
- **关键台词**：我们卖的不是功能，是「被听见」这件事，而它的边际成本是 1 块钱
- **时长**：1.5 分钟

## P10 增长飞轮 + 团队 + Ask

- **要说服什么**：钱怎么变成用户，用户怎么变成钱，你要多少钱换多少里程碑
- **页面内容**：
  - 飞轮：发布 → 平台多一条可发现内容 + 邀请码奖励（>3 期后每期 +1）→ 新用户 → 更多发布；RSS 把频道带进用户自己的播客客户端（绕过平台内获客）+ SSR 内容站 SEO
  - 团队：创始人（一句话背景 + 为什么是这个人；单人即团队的事实不回避，讲成执行力证明）
  - 三幕路线：楔子（对话→节目）→ 形态（消费端验证：圈外收听 / 二次发布率 / 类型分化）→ 平台（创作者经济全层）
  - Ask：金额 + 12-18 个月 runway + 90 天里程碑（30 天 100 频道 → 60 天首批付费 → 90 天消费端三指标达标）
  - 资金用途：发布上线、扩展商店上架、内容审核 v2、移动端评估、品类营销
- **视觉**：飞轮图 + 里程碑时间轴
- **关键台词**：每一期节目都是我们的地推——用户发布即增长
- **时长**：2 分钟（收尾留一句话给愿景：对话正在成为新一代内容资产，我们让每个人拥有它）

## 附录 B — Demo 脚本（P5 逐秒版）

1. **采集**（0:00-0:20）：打开一段真实对话（主题：选一个有大众共鸣的，如「用 AI 规划一次旅行」）→ 点扩展 → 解析预览弹出 → 跳转工作台
2. **润色**（0:20-1:00）：质量门通过提示 → 一键润色流式出稿 → 展示「更简短」方向重润 → 手动改一句话（展示可编辑）
3. **生成**（1:00-2:00）：提交 → 安全审核 → TTS 进度条 → **播放 30 秒成品**（提前剪好片段，含片头 + 主持人第一句，确保现场放得响）
4. **发布**（2:00-2:30）：填标题/封面 → 发布 → 打开播客客户端（Apple Podcasts/小宇宙）演示 RSS 订阅 → 首页看到频道
5. 降级预案：全程录屏版备用；音频文件本地备一份

## 附录 C — Q&A 预判（高频问题与应答要点）

| 问题 | 应答要点 |
|---|---|
| 谁在付费？为什么？ | 锚定创作者：想做播客但被门槛挡住的人；「被听见」是刚需；参考剪映的创作者规模 |
| 复购/留存怎么看？ | 频道是资产（订阅关系迁移成本）；邀请码飞轮制造持续发布动机 |
| 和播客托管平台什么关系？ | 不做托管红海，做创作管线 + 分发闭环；托管是商品层 |
| 内容会不会无聊？ | 润色管线把对话压缩成 5-10 分钟结构化节目；demo 即答案 |
| 为什么选播客不选短视频？ | 对话是口语的；RSS 开放分发规避平台锁死；短视频是 OpenAI Stories 的红海 |
| 法律风险？ | 本人录音同意 + 双审核门 + 举报下架；大厂不敢碰正是我们的空间 |
| 如果 ChatGPT 做了呢？ | 它做「导出按钮」也搬不走订阅者与频道（§3 Q1 话术） |
| 为什么是你？ | 结构判断（大厂推演）+ 执行速度（全链路代码数天跑通） |
